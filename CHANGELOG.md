# Changelog

All notable changes to this agent are tracked here.

## [1.1.0] - 2026-11-10

- Clear communication rule in the Claude Code and Codex definitions. User-facing explanations use clear, simple English, or the language the user requests: short sentences, familiar words, and technical terms explained on first use. Say what a change does and why in terms a non-programmer can follow, and keep exact file paths, names, evidence, risks, and technical detail. Do not invent code locations or claim checks ran when they did not.
- Document this agent as part of MyDevFactory (https://github.com/dimitriskl/mydevfactory).

## [1.0.0] - 2026-11-04

- Initial public, platform-specific Claude Code + Codex distribution.
- MIT license and step-by-step project/personal installation instructions.
- Version declarations and immutable versioned release snapshots.
